Was ist HTML?

HTML steht für HyperText Markup Language – also eine Auszeichnungssprache, keine Programmiersprache. Sie beschreibt die logische Struktur einer Webseite, also welche Inhalte Überschriften, Absätze, Listen oder Links sind.

Merke

HTML beschreibt den Inhalt und seine Bedeutung. Das Aussehen wird später mit CSS festgelegt, und das Verhalten (Interaktion) mit JavaScript.

Eine HTML-Datei besteht aus sogenannten Tags, die den Inhalt umschließen. Tags werden mit spitzen Klammern geschrieben und kommen meist als öffnendes und schließendes Paar:

HTML 
<p>Das ist ein Absatz.</p>
<p>Das ist ein verschachtelter Absatz mit <a href="#">Link</a></p>
Grundregel
  • Alle Tags werden in spitzen Klammern < > geschrieben.
  • Fast jedes öffnende Tag braucht ein schließendes Tag.
  • Tags können verschachtelt werden, müssen aber richtig geschlossen werden.
Richtig verschachtet 
<p>Das ist ein verschachtelter Absatz mit 
    <a href="#">Link</a>
</p>

Das öffnende <a>-Tag befinden sich MIT dem schließenden </a>-Tag INNERHALB des <p> </p>-Tags

Falsch verschachtelt 
<p>Das ist ein verschachtelter Absatz mit 
    <a href="#">Link
</p></a>

Das schließende </a>-Tag ist außerhalb vom schließenden </p>-Tag platziert

Grundstruktur einer HTML-Datei

Jede HTML-Seite folgt einem festen Aufbau. Dieser besteht aus zwei Hauptbereichen:

  • <head> – für technische Infos wie Titel, Zeichensatz und CSS-Verlinkungen.
  • <body> – für alles, was der Besucher tatsächlich sieht.
HTML 
<!DOCTYPE html>
<html lang="de">
<head>
    <meta charset="UTF-8">
    <title>Meine erste Seite</title>
</head>

<body>
    <h1>Hallo Welt!</h1<
    <p>Das ist meine erste Webseite.</p>
</body>
</html>
Tag Bedeutung
<> Die spitzen Klammern kennzeichnen HTML-Tags. Sie werden verwendet, um den Namen eines Elements einzuschließen, z. B. <html>.
</> Ein Schrägstrich innerhalb der spitzen Klammern markiert das Ende eines Elements. So wird aus <html> das passende End-Tag </html>. Start- und End-Tag umschließen in der Regel den Inhalt eines HTML-Elements. Einige Elemente kommen jedoch nur als einzelnes Tag vor.
<!DOCTYPE html> Informiert den Browser darüber, dass es sich bei dem Dokument um eine HTML5-Seite handelt.
<html lang="de"> Das öffnende <html>-Tag bildet den Anfang der HTML-Struktur und umfasst alle weiteren Seitenelemente. Das Attribut lang="de" legt die Sprache der Seite fest – in diesem Fall Deutsch.
</html> Beendet den HTML-Dokumentenbaum und markiert somit das Ende des Dokuments.
lang="de" Dieses Attribut weist auf die Hauptsprache der Seite hin. Es unterstützt Suchmaschinen und Screenreader bei der richtigen Interpretation der Inhalte.
<head> </head> Der Kopfbereich eines HTML-Dokuments. Er enthält Meta-Informationen, den Titel der Seite, Verweise auf Stylesheets und Skripte – also Elemente, die im Browser selbst nicht sichtbar sind.
<meta charset="UTF-8" /> Legt die Zeichenkodierung der Seite fest. Mit UTF-8 lassen sich nahezu alle Schriftzeichen weltweit korrekt darstellen.
<title>Ihr Seitentitel</title> Definiert den Titel der Webseite, der im Browser-Tab oder in Suchergebnissen angezeigt wird.
<body> </body> Beinhaltet alle sichtbaren Inhalte der Webseite – also Texte, Bilder, Links, Überschriften und andere Elemente, die im Browser angezeigt werden.
Erklärung
  • <!DOCTYPE html> legt fest, dass es sich um HTML5 handelt.
  • lang="de" hilft Browsern und Suchmaschinen, die Sprache zu erkennen.
  • <meta charset="UTF-8"> sorgt dafür, dass Umlaute korrekt dargestellt werden.

HTML-Kommentare

Kommentare sind Notizen im Code, die der Browser ignoriert. Sie helfen dir und anderen Entwicklern, den Code besser zu verstehen.

HTML 
<!-- Das ist ein Kommentar -->
<p>Dieser Text wird angezeigt.</p>

<!-- 
    Mehrzeilige Kommentare
    sind auch möglich
-->
Wann Kommentare nutzen?
  • Um komplexe Abschnitte zu erklären
  • Um Code vorübergehend zu deaktivieren
  • Um Bereiche zu markieren (z.B. "Header Beginn")
  • Um TODOs für später zu notieren
Achtung!

Kommentare sind im Quellcode für jeden sichtbar! Schreibe keine sensiblen Informationen wie Passwörter oder interne Notizen in HTML-Kommentare.

HTML-Attribute verstehen

Attribute geben HTML-Elementen zusätzliche Informationen. Sie stehen immer im öffnenden Tag und haben meist die Form attribut="wert".

HTML 
<a href="https://example.com" target="_blank">Link</a>

<img src="bild.jpg" alt="Beschreibung" width="300">

Die wichtigsten Attribute

Attribut Verwendung Beispiel
href Link-Ziel bei <a> href="seite.html"
src Quelle bei Bildern, Videos, Scripts src="logo.png"
alt Alternativtext für Bilder alt="Logo"
class CSS-Klasse zuweisen class="button"
id Eindeutige ID vergeben id="header"
style Inline-CSS - Nicht Empfohlen! (→ s. Sicherheit) style="color: red;"
Wichtig
  • Attributwerte werden in Anführungszeichen geschrieben (doppelte oder einfache)
  • Mehrere Attribute werden mit Leerzeichen getrennt
  • Die Reihenfolge der Attribute spielt keine Rolle

Block- vs. Inline-Elemente

HTML-Elemente verhalten sich unterschiedlich im Layout. Es gibt zwei Haupttypen:

Block-Elemente

Nehmen die volle Breite ein und beginnen immer in einer neuen Zeile.

  • <div>
  • <p>
  • <h1> bis <h6>
  • <ul>, <ol>
  • <header>, <footer>, <section>
HTML 
<div>Block 1</div>
<div>Block 2</div>
<p>Ein Absatz</p>

Inline-Elemente

Nehmen nur so viel Platz ein, wie ihr Inhalt benötigt. Stehen nebeneinander in der Zeile.

  • <span>
  • <a>
  • <strong>, <em>
  • <img>
  • <code>
CSS 
<p>Das ist <strong>fett</strong> und <em>kursiv</em>.

<span>Inline 1</span> <span>Inline 2</span>
Merke
  • <div> = neutraler Block-Container (für Layouts)
  • <span> = neutraler Inline-Container (für Text-Styling)
  • Block-Elemente können Inline-Elemente enthalten, aber nicht umgekehrt!

Richtig verschachteln

HTML-Elemente können ineinander verschachtelt werden – aber die Reihenfolge beim Schließen ist wichtig!

Richtig verschachtelt 
<p>Das ist <strong>fett und <em>kursiv</em></strong>.</p>

<div>
    <h2>Titel</h2>
    <p>Text</p>
</div>
Falsch verschachtelt 
<!-- Tags überschneiden sich! -->
<p>Das ist <strong>fett und <em>kursiv</strong></em>.</p>

<!-- Inline-Element enthält Block-Element -->
<span><div>Falsch!</div></span>
Goldene Regel

Was zuerst geöffnet wird, muss zuletzt geschlossen werden – wie Klammern in der Mathematik!

Selbstschließende Tags

Manche Tags haben keinen Inhalt und schließen sich selbst:

HTML 
<img src="bild.jpg" alt="Bild">
<br>
<hr>
<input type="text">
<meta charset="UTF-8">

HTML Entities & Sonderzeichen

Manche Zeichen haben in HTML eine besondere Bedeutung, wie < und >. Um sie als Text anzuzeigen, braucht man HTML Entities.

Zeichen Entity Beschreibung
< &lt; Kleiner als (less than)
> &gt; Größer als (greater than)
& &amp; Kaufmännisches Und (ampersand)
" &quot; Anführungszeichen
(Leerzeichen) &nbsp; Geschütztes Leerzeichen (non-breaking space)
© &copy; Copyright-Symbol
€ &euro; Euro-Symbol

Beispiel

CSS 
<p>Um HTML-Tags anzuzeigen: &lt;p&gt;Text&lt;/p&gt; → <p>Text</p>
<p>Preis: 49&euro; &nbsp;inkl. MwSt.</p> → <p>Preis: 49€ inkl. MwSt.</p>
Hinweis

Mit charset="UTF-8" im <head> kannst du die meisten Sonderzeichen (wie ä, ö, ü) direkt schreiben. Nur für HTML-reservierte Zeichen brauchst du Entities!

Wichtige HTML-Elemente

Es gibt hunderte HTML-Tags, aber ein paar Grundelemente solltest du unbedingt kennen:

Textelemente

  • <h1> bis <h6> – Überschriftenebenen
  • <p> – Absatz
  • <strong> – wichtiger Text (fett)
  • <em> – betonter Text (kursiv)
HTML 
<h1>Willkommen!</h1>
<p>Das ist ein <strong>Beispiel</strong> mit <em>Textauszeichnung</em>.</p>

Listen & Links

  • <ul> – ungeordnete Liste
  • <ol> – nummerierte Liste
  • <a href="..."> – Link
HTML 
<ul>
    <li>Apfel</li>
    <li>Birne</li>
</ul>

<a href="https://example.com">Zur Website</a>

Container Elemente

  • <div> – generischer Block-Container
  • <span> – generischer Inline-Container

Diese beiden Tags sind die "Allzweckwaffen" für Layouts und Styling. Sie haben keine semantische Bedeutung, sind aber extrem nützlich!

HTML 
<div class="container">
    <p>Text mit <span class="highlight">Hervorhebung</span></p>
</div>

HTML Cheat Sheet – Die Top 15 Tags

Diese Tags brauchst du in fast jedem HTML-Projekt:

<html> – Root-Element
<head> – Metadaten
<body> – Sichtbarer Inhalt
<h1>-<h6> – Überschriften
<p> – Absatz
<a> – Link
<div> – Block-Container
<span> – Inline-Container
<img> – Bild
<ul> – Ungeordnete Liste
<ol> – Nummerierte Liste
<li> – Listenpunkt
<strong> – Wichtig (fett)
<em> – Betont (kursiv)
<br> – Zeilenumbruch
Tipp

Lerne diese 15 Tags auswendig – damit kannst du bereits 80% aller Webseiten verstehen und selbst bauen!

Gute Praxis beim HTML-Schreiben

  • Verwende semantische Tags (z. B. <header>, <main>, <footer>) statt nur <div>.
  • Halte deinen Code einheitlich eingerückt – das erleichtert das Lesen.
  • Schreibe alle Tags klein (HTML ist zwar nicht case-sensitive, aber das ist Standard).
  • Füge sinnvolle alt-Texte bei Bildern hinzu – das verbessert Barrierefreiheit und SEO.
  • Validiere deinen Code mit dem W3C Validator – so findest du Fehler.
  • Nutze Kommentare für komplexe Bereiche, aber übertreibe es nicht.
  • Achte auf korrekte Verschachtelung – schließe Tags in der richtigen Reihenfolge.
Tipp

HTML ist schnell gelernt, aber gutes HTML ist sauber, logisch und leicht erweiterbar. Je besser deine Struktur, desto einfacher wird später das Styling mit CSS und die Wartung deines Codes!

Warum ist sauberer HTML-Code wichtig?

  • SEO: Suchmaschinen bevorzugen strukturierten, validen HTML-Code
  • Accessibility: Screenreader funktionieren besser mit semantischem HTML
  • Wartbarkeit: Du und andere Entwickler verstehen den Code schneller
  • Performance: Browser können optimiertes HTML schneller verarbeiten
  • Zukunftssicherheit: Standards sorgen für Kompatibilität
