Die Navigation

Die Navigation ist das Rückgrat jeder Website – sie führt Besucher durch deine Inhalte und hilft, Struktur und Orientierung zu schaffen. Eine klare, semantische Navigation ist nicht nur für Benutzer, sondern auch für Suchmaschinen wichtig.

Was ist eine Navigation?

Eine Navigation ist eine strukturierte Liste von Links, die zu den wichtigsten Bereichen einer Webseite führen. Sie wird typischerweise im <header> platziert.

Warum eine Liste?

HTML-Navigationen werden als Liste geschrieben, weil sie eine geordnete, zugängliche Struktur schaffen. Screenreader und Suchmaschinen können so besser verstehen, wie sich die Seiten untereinander verknüpfen.

Merke

Navigation hilft den Nutzern, die Struktur deiner Webseite zu verstehen und Inhalte schnell zu finden. Suchmaschinen erkennen ebenfalls die Linkstruktur.

HTML-Grundstruktur einer Navigation

Eine Navigation besteht aus einer ungeordneten Liste <ul>, in der jeder Menüpunkt als <li> steht. Die eigentlichen Links werden mit <a> – Ankern – umgesetzt.

Tag Bedeutung
<nav> Semantisches Element für Navigation. Enthält alle Links der Hauptnavigation.
<ul> Ungeordnete Liste, die die einzelnen Navigationspunkte enthält.
<li> Listenelement für einen einzelnen Navigationspunkt.
<a href="..."> Link zu einer anderen Seite oder einem Abschnitt der Seite.
HTML 
<nav class="navbar-demo">
    <ul class="menu">
        <li><a href="index.html">Home</a></li>
        <li><a href="about.html">Über uns</a></li>
        <li><a href="contact.html">Kontakt</a></li>
    </ul>
</nav>

Später mit CSS oder JS erweitern

Per CSS kannst du mit Hilfe der zugewiesenen Klassen wie hier .navbar-demo oder .menu geziehlt gestalten. Beispielsweise ein Dropdown selbst ist zunächst unsichtbar. Mit :hover oder kleinen JavaScript-Funktionen kannst du es ein- und ausblenden. Wichtig ist: Der HTML-Aufbau steht schon jetzt korrekt.

CSS ansehen
CSS 
.navbar-demo {
    padding-left: 30px;                    /* Abstand von links, um den Inhalt etwas einzurücken */
    background: var(--dark-light);         /* Hintergrundfarbe aus deiner Farbpalette */
    border-radius: 0 8px 8px 0;            /* Abgerundete rechte Ecken für weiches Design */
    border-left: 4px solid var(--accent);  /* Farbakzent am linken Rand (z. B. Kiwi-Grün oder Orange) */
}

.menu {
    display: flex;                         /* Aktiviert Flexbox für horizontale Anordnung */
    gap: 2rem;                             /* Abstand zwischen den einzelnen Menü-Links */
    list-style: none;                      /* Entfernt Aufzählungspunkte */
    align-items: center;                   /* Vertikale Zentrierung der Listenelemente */
}

Navigation im Header

Der richtige Platz für deine Navigation

In den meisten Fällen befindet sich die Navigation im <header> – dem Kopfbereich der Website. So bleibt sie auf jeder Unterseite sichtbar und sorgt für ein konsistentes Nutzererlebnis. Eine Navigation kann aber auch an anderen Stellen platziert werden, wie du anhand der Demos siehst.

Ein einfaches Beispiel für einen Header mit Navigation:

HTML 
<header>
    <div class="demo-header">
        <nav class="nav-demo">
            <a href="#" class="logo">
                <img src="/assets/icons/logo.svg" alt="Logo">
            </a>

            <ul>
                <li><a href="#">Home</a></li>
                <li><a href="#">Über uns</a></li>
                <li><a href="#">Kontakt</a></li>
            </ul>
        </nav>
    </div>
</header>

Navigation mit Unterpunkten (Dropdown)

Wenn deine Website viele Themenbereiche hat, kannst du Unterpunkte anlegen. Diese Struktur nennt man Dropdown-Menü. Es wird meist mit CSS oder JavaScript sichtbar gemacht.

HTML 
<div class="demo-header">
    <nav class="nav-demo">
        <a href="#" class="logo">
            <img src="/assets/icons/logo.svg" alt="Logo">
        </a>

        <ul class="menu">
            <li><a href="#">Home</a></li>

            <li class="dropdown-demo">
                <a href="#">Themen</a>
                <ul class="dropdown-menu-demo">
                    <li><a href="#">HTML</a></li>
                    <li><a href="#">CSS</a></li>
                    <li><a href="#">JavaScript</a></li>
                </ul>
            </li>
        </ul>
    </nav>
</div>

Häufiges Problem: Dropdown-Text sitzt versetzt

Fällt dir auf, dass "Themen" (mit Dropdown) höher sitzt als "Home"? Das liegt daran, dass das <li> mit Dropdown ein zusätzliches Kind-Element hat – die verschachtelte <ul>. Auch wenn diese mit position: absolute aus dem Fluss genommen wird, kann sie die Baseline des Eltern-Elements beeinflussen.

Die Lösung: Setze auf alle <li>-Elemente im Hauptmenü ein einheitliches vertical-align:

.menu-demo > li {
    position: relative;
    vertical-align: middle;    /* Alle li auf gleicher Höhe */
}

Alternativ kannst du auch vertical-align: top verwenden. Das Wichtige ist, dass alle Menüpunkte denselben Wert haben.

Dropdown auf Klick (Click-Variante)

Bei Touch-Geräten oder wenn der User mehr Kontrolle haben soll, ist es oft besser, Dropdowns erst bei Klick zu öffnen statt bei Hover. Das braucht ein bisschen JavaScript.

HTML 
<nav>
    <ul class="menu-click">
        <li><a href="#">Home</a></li>
        <li class="dropdown-click">
            <a href="#">Themen</a>
            <ul class="dropdown-menu-click">
                <li><a href="#">HTML</a></li>
                <li><a href="#">CSS</a></li>
                <li><a href="#">JavaScript</a></li>
            </ul>
        </li>
    </ul>
</nav>

Details zum JavaScript
JavaScript 
// Alle Dropdown-Trigger finden
document.querySelectorAll('.dropdown-click > a').forEach(trigger => {
    trigger.addEventListener('click', function(e) {
        e.preventDefault();                     // Link-Verhalten verhindern
        
        const dropdown = this.parentElement;    // Das li.dropdown-click
        
        // Alle anderen Dropdowns schließen
        document.querySelectorAll('.dropdown-click.open').forEach(open => {
            if (open !== dropdown) {
                open.classList.remove('open');
            }
        });
        
        // Dieses Dropdown togglen
        dropdown.classList.toggle('open');
    });
});

// Klick außerhalb schließt alle Dropdowns
document.addEventListener('click', function(e) {
    if (!e.target.closest('.dropdown-click')) {
        document.querySelectorAll('.dropdown-click.open').forEach(open => {
            open.classList.remove('open');
        });
    }
});

Details zum JavaScript (erweitert für Sub-Menüs)
JavaScript 
// Haupt-Dropdowns
document.querySelectorAll('.dropdown-click > a').forEach(trigger => {
    trigger.addEventListener('click', function(e) {
        e.preventDefault();
        const dropdown = this.parentElement;
        
        // Andere Haupt-Dropdowns schließen
        document.querySelectorAll('.dropdown-click.open').forEach(open => {
            if (open !== dropdown) {
                open.classList.remove('open');
                // Sub-Menüs auch schließen
                open.querySelectorAll('.dropdown-sub-click.open').forEach(sub => {
                    sub.classList.remove('open');
                });
            }
        });
        
        dropdown.classList.toggle('open');
    });
});

// Sub-Dropdowns
document.querySelectorAll('.dropdown-sub-click > a').forEach(trigger => {
    trigger.addEventListener('click', function(e) {
        e.preventDefault();
        e.stopPropagation();                    // Verhindert Schließen des Haupt-Dropdowns
        
        const subDropdown = this.parentElement;
        
        // Andere Sub-Dropdowns auf gleicher Ebene schließen
        const siblings = subDropdown.parentElement.querySelectorAll('.dropdown-sub-click.open');
        siblings.forEach(open => {
            if (open !== subDropdown) {
                open.classList.remove('open');
            }
        });
        
        subDropdown.classList.toggle('open');
    });
});

// Klick außerhalb schließt alles
document.addEventListener('click', function(e) {
    if (!e.target.closest('.dropdown-click') && !e.target.closest('.dropdown-sub-click')) {
        document.querySelectorAll('.dropdown-click.open, .dropdown-sub-click.open').forEach(open => {
            open.classList.remove('open');
        });
    }
});

Skip-Link (Sprungnavigation)

Ein Skip-Link ermöglicht es Tastatur- und Screenreader-Nutzern, direkt zum Hauptinhalt zu springen – ohne sich durch die gesamte Navigation zu arbeiten. Er ist normalerweise unsichtbar und erscheint erst bei Fokus.

HTML 
<!-- Ganz am Anfang des body -->
<a href="#main-content" class="skip-link">Zum Inhalt springen</a>

<header>
    <!-- Navigation hier -->
</header>

<main id="main-content">
    <!-- Hauptinhalt -->
</main>

Demo: Klicke in die Box und drücke Tab, um den Skip-Link zu sehen:

Details zum CSS
CSS 
.skip-link {
    position: absolute;
    top: -100px;                        /* Versteckt außerhalb des Viewports */
    left: 50%;
    transform: translateX(-50%);
    background: var(--accent-blue);
    color: white;
    padding: 0.75rem 1.5rem;
    border-radius: 0 0 8px 8px;
    text-decoration: none;
    font-weight: 600;
    z-index: 1000;
    transition: top 0.3s;
}

.skip-link:focus {
    top: 0;                             /* Wird sichtbar bei Tastatur-Focus */
}
Warum ist das wichtig?

Stell dir vor, du müsstest bei jeder Seite erst 20 Navigationslinks durchdrücken, bevor du zum eigentlichen Inhalt kommst. Für Tastaturnutzer ist das Alltag – ein Skip-Link macht den Unterschied zwischen frustrierend und nutzbar.

Breadcrumb-Navigation

Breadcrumbs (Brotkrümel) zeigen dem Nutzer, wo er sich in der Seitenhierarchie befindet. Sie sind besonders wichtig für SEO und die Orientierung auf größeren Websites.

HTML 
<nav aria-label="Breadcrumb">
    <ol class="breadcrumb">
        <li><a href="/">Home</a></li>
        <li><a href="/tutorials/">Tutorials</a></li>
        <li><a href="/tutorials/html/">HTML</a></li>
        <li><a href="#" aria-current="page">Navigation</a></li>
    </ol>
</nav>
  1. Home
  2. Tutorials
  3. HTML
  4. Navigation
Details zum CSS
CSS 
.breadcrumb {
    list-style: none;
    display: flex;
    flex-wrap: wrap;                    /* Umbruch bei wenig Platz */
    padding: 0.75rem 1rem;
    margin: 0;
    background: var(--bg-secondary);
    border-radius: 8px;
}

.breadcrumb li {
    display: flex;
    align-items: center;
}

/* Trennzeichen zwischen den Elementen */
.breadcrumb li + li::before {
    content: '/';                       /* Oder '›' oder '→' */
    padding: 0 0.5rem;
    color: var(--text-secondary);
}

.breadcrumb a {
    color: var(--accent-blue);
    text-decoration: none;
}

.breadcrumb a:hover {
    text-decoration: underline;
}

/* Aktuelle Seite (nicht klickbar) */
.breadcrumb [aria-current="page"] {
    color: var(--text-secondary);
    pointer-events: none;
}
Warum <ol> statt <ul>?

Breadcrumbs haben eine klare Reihenfolge (Home → Kategorie → Unterkategorie → Seite), daher ist eine geordnete Liste (<ol>) semantisch korrekter. Screenreader geben dann auch "Element 1 von 4" aus.

Details zum JavaScript
JavaScript 
const hamburgerBtn = document.querySelector('.hamburger-btn');
const mobileMenu = document.querySelector('.mobile-menu');

hamburgerBtn.addEventListener('click', function() {
    // Button-Animation togglen
    this.classList.toggle('active');
    
    // Menü öffnen/schließen
    mobileMenu.classList.toggle('open');
    
    // Accessibility: aria-expanded aktualisieren
    const isOpen = mobileMenu.classList.contains('open');
    this.setAttribute('aria-expanded', isOpen);
    this.setAttribute('aria-label', isOpen ? 'Menü schließen' : 'Menü öffnen');
});

Active State (Aktuelle Seite markieren)

Der aktuelle Menüpunkt sollte visuell hervorgehoben werden, damit Nutzer wissen, wo sie sich befinden. Hier sind verschiedene Methoden, das umzusetzen.

HTML 
<!-- Methode 1: Klasse -->
<nav>
    <ul>
        <li><a href="/">Home</a></li>
        <li><a href="/about/" class="active">Über uns</a></li>
        <li><a href="/contact/">Kontakt</a></li>
    </ul>
</nav>

Accessibility Best Practices

Eine barrierefreie Navigation ist nicht nur nett, sondern in vielen Ländern gesetzlich vorgeschrieben. Hier die wichtigsten Punkte zusammengefasst:

ARIA-Attribute für Dropdowns

HTML 
<nav aria-label="Hauptnavigation">
    <ul>
        <li><a href="/">Home</a></li>
        <li>
            <!-- Button für Dropdown (nicht Link!) -->
            <button 
                aria-expanded="false" 
                aria-haspopup="true"
                aria-controls="dropdown-menu">
                Themen
            </button>
            <ul id="dropdown-menu">
                <li><a href="/html/">HTML</a></li>
                <li><a href="/css/">CSS</a></li>
            </ul>
        </li>
    </ul>
</nav>

Wichtige ARIA-Attribute erklärt

Attribut Bedeutung
aria-label Benennt die Navigation (z.B. "Hauptnavigation", "Footer-Links")
aria-expanded Zeigt an, ob ein Dropdown offen (true) oder geschlossen (false) ist
aria-haspopup Signalisiert, dass ein Element ein Popup/Dropdown öffnet
aria-controls Verknüpft Button mit dem gesteuerten Element (per ID)
aria-current Markiert die aktuelle Seite ("page") oder Position

Keyboard-Navigation

Nutzer müssen die Navigation komplett mit der Tastatur bedienen können:

JavaScript 
// Keyboard-Support für Dropdowns
document.querySelectorAll('.dropdown button').forEach(button => {
    button.addEventListener('keydown', function(e) {
        const dropdown = this.nextElementSibling;
        
        switch(e.key) {
            case 'Enter':
            case ' ':                           // Leertaste
                e.preventDefault();
                toggleDropdown(this, dropdown);
                break;
                
            case 'Escape':
                closeDropdown(this, dropdown);
                this.focus();                   // Focus zurück auf Button
                break;
                
            case 'ArrowDown':
                e.preventDefault();
                if (dropdown.classList.contains('open')) {
                    // Zum ersten Link im Dropdown
                    dropdown.querySelector('a').focus();
                } else {
                    toggleDropdown(this, dropdown);
                }
                break;
        }
    });
});

// In Dropdown-Links navigieren
document.querySelectorAll('.dropdown-menu a').forEach(link => {
    link.addEventListener('keydown', function(e) {
        const items = [...this.closest('ul').querySelectorAll('a')];
        const index = items.indexOf(this);
        
        switch(e.key) {
            case 'ArrowDown':
                e.preventDefault();
                items[index + 1]?.focus();
                break;
                
            case 'ArrowUp':
                e.preventDefault();
                items[index - 1]?.focus();
                break;
                
            case 'Escape':
                // Dropdown schließen, Focus auf Button
                const button = this.closest('.dropdown').querySelector('button');
                closeDropdown(button, this.closest('ul'));
                button.focus();
                break;
        }
    });
});
Checkliste für barrierefreie Navigation
  • ☐ Skip-Link vorhanden
  • ☐ <nav> mit aria-label
  • ☐ Alle Links per Tab erreichbar
  • ☐ Sichtbarer Focus-Indikator - nie outline: none!
  • ☐ Dropdowns mit Enter/Space öffnen
  • ☐ Escape schließt Dropdowns
  • ☐ Pfeiltasten für Navigation in Dropdowns
  • ☐ aria-expanded wird aktualisiert
  • ☐ Aktuelle Seite mit aria-current="page"
