In diesem Tutorial erstellst du eine kleine ToDo-App mit HTML, CSS und JavaScript. Sie läuft komplett im Browser und speichert deine Aufgaben im localStorage.

Meine Aufgaben

    Code verstehen

    Die App nutzt localStorage, um Aufgaben im Browser zu speichern. Wenn du die Seite neu lädst, bleiben sie erhalten.

    // Aufgaben speichern
localStorage.setItem("todos", JSON.stringify(todos));

// Aufgaben laden
let todos = JSON.parse(localStorage.getItem("todos")) || [];

// Aufgabe hinzufügen
function addNewTodo() {
  const text = todoInput.value.trim();
  if (text === "") return;
  todos.push({ text, done: false });
  saveTodos();
}

    Die Funktionen toggleDone() und deleteTodo() ändern bzw. löschen Aufgaben und aktualisieren dann den Speicher.

    Weiterführende Ideen

    • Filtere nach „Erledigt“ / „Offen“
    • Füge ein Datum hinzu
    • Nutze localStorage.clear() für einen Reset-Button
