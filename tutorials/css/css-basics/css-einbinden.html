Was ist CSS?

CSS (Cascading Style Sheets) ist die Sprache für das Design deiner Webseite.

Reset / Normalize

Bevor du mit dem Pixelschubsen beginnst, legst du zunächst das Grundgerüst an – meist in einer Datei namens style.css. Diese dient als Startseite und wird automatisch geladen, wenn jemand deine Domain aufruft. Du kannst sie in einem einfachen Texteditor anlegen.

Zu Beginn setzt du Browser-Standardstile zurück oder gleichst sie an.

CSS 
/* 1. Reset oder Normalize */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

So vermeidest du, dass jedes Element - z. B. <p> oder <ul> - eigene ungewollte Abstände hat.

Grundlegende Layout-Definition

Hier folgen Basis-Styles für den gesamten Aufbau: Schriftarten, Farben, Hintergrund.

CSS 
/* 2. Grundlegende Layout-Definition */

css {
    scroll-behavior: smooth;
}

body {
    font-family: "Open Sans", sans-serif;
    font-size: 16px;
    line-height: 1.6;
    color: #222;
    background-color: #fdfdfd;
}

HTML5-Struktur-Elemente (ohne Punkt)

Seit HTML5 kannst du <header>, <main>, <footer>, <nav>, <section>, <article> usw. direkt ansprechen, ohne Punkt – weil sie echte Tags sind, keine Klassen.

CSS 
/* 3. HTML5-Struktur-Elemente */

header {
    background-color: #333;
    color: #fff;
    padding: 20px 0;
}

main {
    padding: 60px 0;
}

footer {
    background-color: #222;
    color: #ccc;
    padding: 40px 0;
    text-align: center;
}

Wiederverwendbare Klassen (mit Punkt .)

Das ist dein „Werkzeugkasten" für Layout und Gestaltung. Hier kommen Hilfsklassen und Komponenten, die du mehrfach brauchst.

CSS 
/* 4. Allgemeine, wiederverwendbare Klassen */

.container {
    max-width: 1000px;
    margin: 0 auto;
    padding: 0 20px;
}

.bg-light { background-color: #f6f8f6; }
.bg-dark  { background-color: #333; color: #fff; }

.text-center { text-align: center; }
.mt-2 { margin-top: 20px; }
.pt-4 { padding-top: 40px; }

Navigation, Header, Footer im Detail

Jetzt folgen gezielte Layouts für die Hauptbereiche deiner Seite:

CSS 
/* 5. Header, Navigation, Footer */

header nav ul {
    list-style: none;
    display: flex;
    gap: 20px;
    justify-content: center;
}

header nav a {
    color: #fff;
    text-decoration: none;
    font-weight: bold;
}

header nav a:hover {
    text-decoration: underline;
}

Inhaltselemente (Sections, Articles, Cards, etc.)

Ab hier wird's seiten- oder bereichsspezifisch:

CSS 
/* 6. Inhaltsbereiche */

section {
    padding: 60px 0;
}

section h2 {
    margin-bottom: 20px;
    color: #333;
}

.card {
    background: #fff;
    border-radius: 10px;
    box-shadow: 0 2px 8px rgba(0,0,0,0.1);
    padding: 20px;
}

Typografie

Hier kannst du Headings und Text global festlegen:

CSS 
/* 7. Typografie */

h1, h2, h3, h4 {
    font-family: "Montserrat", sans-serif;
    line-height: 1.2;
}

p {
    margin-bottom: 1rem;
}

Utilities / Hilfsklassen

Zum Schluss kleine Helfer für schnelle Anpassungen:

CSS 
/* 8. Utilities */

.hidden { display: none; }
.bold { font-weight: bold; }
.uppercase { text-transform: uppercase; }
.text-center { text-align: center; }
.text-right { text-align: right; }
.text-left { text-align: left; }
.mt-1 { margin-top: 10px; }
.mt-2 { margin-top: 20px; }
.mb-1 { margin-bottom: 10px; }
.mb-2 { margin-bottom: 20px; }
.pt-1 { padding-top: 10px; }
.pt-2 { padding-top: 20px; }
.pb-1 { padding-bottom: 10px; }
.pb-2 { padding-bottom: 20px; }
.float-left { float: left; }
.float-right { float: right; }
.clear { clear: both; }
